Supabase Live Integration Setup

The platform operates out of the box in High-Fidelity Synthetic In-Memory Mode for offline hackathon evaluations.

To connect your live Supabase PostgreSQL cloud instance:

  1. Create a free project at supabase.com.
  2. Open the SQL Editor in your Supabase dashboard and run schema.sql and seed.sql.
  3. Go to Project Settings ➔ API and copy your Project URL and anon public key.
  4. Create a .env file in your project root with:
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-supabase-publishable-key
SECRET_KEY=cyber-soc-ntro-secret-key-2026

Upon restart with python app.py, the backend will automatically connect to Supabase PostgreSQL.
